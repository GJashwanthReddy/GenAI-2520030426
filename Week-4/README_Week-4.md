# Multilingual Tokenizer Comparison

The main objective of this experiment is to compare how tokenizers process text in different languages.

The program takes sample text and uses tokenizers to split it into tokens, allowing the tokenization results to be compared across languages and text samples.

The experiment includes:

1. **`tokenizer_comparison.py`** → Runs the tokenizer comparison on the selected text samples.
2. **`requirements.txt`** → Lists the packages required for the experiment.

Install the required packages using:

**`python -m pip install -r requirements.txt`**

Run the Python program to view and compare the tokenization results. Token counts and token boundaries can differ depending on the language and tokenizer.
